# CCtools - Blender UV工具集

这是一个Blender插件，提供UV编辑工具集，包括统一UV岛尺寸和放松UV岛功能。

## 功能

### 核心功能
- **统一宽度**：将所有选中的UV岛统一为相同的宽度
- **统一高度**：将所有选中的UV岛统一为相同的高度
- **锁定比例**：在缩放时保持UV岛的宽高比不变
- **重做面板支持**：在Blender的重做面板中提供锁定比例选项
- **放松UV岛**：使用多种算法放松选中的UV岛，减少UV扭曲

### 放松UV岛功能
- **边长度模式**：基于边长度的放松，适用于保持边长比例
- **角度模式**：基于角度的放松，适用于保持角度关系
- **面积模式**：基于面积的放松，适用于保持面积比例
- **可调节强度**：通过放松强度滑块控制放松程度
- **迭代控制**：可设置迭代次数以获得最佳效果

### 实验性功能
- **示例新功能**：展示如何安全地添加新功能（默认禁用，可在设置中启用）

## 安装

1. 下载此仓库的ZIP文件
2. 在Blender中打开 `编辑 > 首选项 > 插件`
3. 点击 `安装...` 并选择下载的ZIP文件
4. 启用 "Ctools" 插件

## 使用方法

### 统一UV岛尺寸
1. 在Blender中打开UV编辑器
2. 选择要处理的UV岛
3. 在侧边栏中找到 "Ctools UV" 面板
4. 使用 "统一宽度" 或 "统一高度" 按钮
5. 可选择启用 "锁定比例" 选项

### 放松UV岛
1. 在Blender中打开UV编辑器
2. 选择要放松的UV岛
3. 在侧边栏中找到 "Ctools UV" 面板
4. 选择放松模式（边长度/角度/面积）
5. 调整放松强度和迭代次数
6. 点击 "放松UV岛" 按钮

### 实验性功能
1. 在Blender中打开UV编辑器
2. 在侧边栏中找到 "Ctools UV" 面板
3. 启用 "启用示例新功能" 选项
4. 使用新功能面板中的操作

## 开发信息

### 版本控制
- 使用语义化版本控制：主版本.次版本.修订版本
- 主版本：不兼容的API修改
- 次版本：向下兼容的功能性新增
- 修订版本：向下兼容的问题修正

### 分支策略
- `main`：稳定发布版本
- `feature-development`：功能开发分支
- 新功能在开发分支上测试完成后合并到主分支

### 添加新功能
1. 创建新功能文件（如 `new_feature.py`）
2. 在新文件中实现功能类和面板
3. 在 `__init__.py` 中使用 try-except 导入新模块
4. 在 register/unregister 函数中添加新功能的注册/注销
5. 更新版本号和文档

### 代码结构
```
CCtools/
├── __init__.py           # 插件入口
├── blender_manifest.toml # 插件清单
├── README.md            # 项目说明
├── uv_tools.py          # UV工具核心功能
└── example_new_feature.py # 示例新功能
```
