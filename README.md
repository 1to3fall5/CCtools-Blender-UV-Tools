# CCtools - Blender UV工具集

这是一个Blender插件，提供了一系列UV编辑工具，帮助您更高效地处理UV贴图。

## 功能概述

### 核心功能

- **统一UV岛尺寸**：将选中的UV岛统一设置为相同的宽度或高度，可选择保持比例
  - 统一宽度：所有选中的UV岛设置为相同的宽度
  - 统一高度：所有选中的UV岛设置为相同的高度
  - 锁定比例：在调整尺寸时保持原始宽高比

- **放松UV岛**：对选中的UV岛应用放松算法，优化UV布局
  - 平均模式：均匀分布UV顶点
  - 边界模式：保持边界形状，放松内部顶点
  - 角度模式：优化UV角度，减少变形

### 实验性功能

- **示例新功能**：展示如何安全地添加新功能的示例

## 安装方法

1. 下载插件文件
2. 在Blender中进入 `编辑 > 首选项 > 插件`
3. 点击 `安装...` 按钮，选择下载的插件文件
4. 启用 "Ctools" 插件

## 使用方法

### 统一UV岛尺寸

1. 在UV编辑器中选择要处理的UV岛
2. 在右侧面板中找到 "Ctools UV" 标签
3. 在 "统一UV岛尺寸" 面板中：
   - 选择缩放模式（宽度或高度）
   - 可选择是否锁定比例
   - 点击相应的按钮执行操作

### 放松UV岛

1. 在UV编辑器中选择要放松的UV岛
2. 在右侧面板中找到 "Ctools UV" 标签
3. 在 "放松UV岛" 面板中：
   - 选择放松模式（平均、边界或角度）
   - 调整放松强度（0.1-1.0）
   - 设置迭代次数（1-10）
   - 点击"放松UV岛"按钮执行操作

## 开发信息

### 版本控制

- 主分支：稳定版本
- feature-development分支：新功能开发分支

### 分支策略

- `main`：稳定发布版本
- `feature-development`：新功能开发和测试
- 新功能先在feature-development分支开发，测试完成后合并到main分支

### 添加新功能

1. 创建新的功能模块文件（如`new_feature.py`）
2. 在`__init__.py`中添加条件导入逻辑
3. 使用try-except结构确保新功能不影响现有功能
4. 更新版本号和文档
