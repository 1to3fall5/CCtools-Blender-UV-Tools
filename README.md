# CCtools - Blender UV工具集

这是一个Blender插件，提供统一UV岛尺寸的工具集，支持统一宽度和高度功能，并可选择锁定宽高比。

## 功能

- **统一宽度**：将所有选中的UV岛统一为相同的宽度
- **统一高度**：将所有选中的UV岛统一为相同的高度
- **锁定比例**：在缩放时保持UV岛的宽高比不变
- **重做面板支持**：在Blender的重做面板中提供锁定比例选项

## 安装

1. 下载此仓库的ZIP文件
2. 在Blender中打开 `编辑 > 首选项 > 插件`
3. 点击 `安装...` 并选择下载的ZIP文件
4. 启用 "Ctools" 插件

## 使用方法

1. 在Blender中打开UV编辑器
2. 选择要处理的UV岛
3. 在侧边栏中找到 "Ctools UV" 面板
4. 使用 "统一宽度" 或 "统一高度" 按钮
5. 可选择启用 "锁定比例" 选项
